A dog reviews its mailman after three years of the same visit — same blue shorts, same bag, same 9 a.m. knock — and never once a treat. The grievance is filed the only way a dog can file anything: 412 complaints, all barking. *"Three years, same blue shorts, same bag, same 9 a.m. knock. He has never once brought me a treat. I have filed 412 complaints. All barking."*

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
